# bolt

Simple and efficient hardware checkout system. Backed by the
[Hexlabs API](https://github.com/HackGT/api).

## Required environment variables

### Frontend

| Variable                  | Description                                                                                                                   |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| REACT_APP_API_ENVIRONMENT | "production" or "development" depending on the environment you want to connect to (local development should be "development") |

## Development

`yarn start` to run the frontend `yarn build` to build the app for production
